# XS File Library

一个基于 FastAPI + HTML + JavaScript + Bootstrap 的轻量级个人文件库系统。

XS File Library是一个基于 FastAPI 开发的轻量级文件管理系统，集成用户认证、角色权限控制、文件上传下载、文件夹管理、文件搜索、用户管理以及深色模式等功能。系统采用前后端分离设计，支持管理员（Admin）、普通用户（User）和访客（Viewer）多级权限管理，实现文件资源的安全存储与共享。通过树形目录结构和直观的管理界面，用户能够方便地进行文件分类、浏览和维护，适用于个人知识库、团队文档库以及内部文件共享场景。支持密码加密存储、主题切换和多文件夹管理，可作为轻量级文档管理平台使用。

## 文件共享

支持通过链接将指定文件共享给其他用户或外部访问者，无需授予系统账号即可快速分发文件资源。

- 一键生成共享链接
- 共享有效期控制

  创建共享时可设置链接有效期，超过有效期后，链接自动失效。可设置为以下几项：

  - 1天
  - 7天
  - 30天
  - 90天
  - 一年

- 共享密码保护

  共享密码采用 SHA256 加密存储，不以明文形式保存在系统中，提升数据安全性。


- 共享记录管理

  共享管理权限可查看所有共享记录，可随时取消共享，链接会立即失效。

- 共享文件夹打包下载

  共享文件夹可以打包为zip格式下载

- 共享查看记录

  共享文件后记录查看记录和查看次数

## 权限管理

精细化权限管理，将权限管理分为用户权限管理和文件夹权限管理两部分：

### 用户权限管理

用户权限管理用于控制系统功能的使用范围，不同用户可根据授予的权限访问对应功能，实现精细化权限控制。

系统采用基于权限项（Permission）的授权模式，每个用户可以拥有一个或多个功能权限，而不再依赖固定角色。管理员可根据实际业务需求灵活分配权限。

#### 支持的权限项

| 权限         | 说明         |
| ------------ | ------------ |
| upload       | 上传文件     |
| download     | 下载文件     |
| delete       | 删除文件     |
| share        | 创建文件共享 |
| share_manage | 管理共享链接 |
| user_manage  | 用户管理     |

由 user_manage 管理员创建用户时进行管理，如需修改权限，需要删除用户后重新建立或者网站管理员后台修改。

### 文件夹权限管理

文件夹权限管理用于控制用户对特定目录的访问权限，实现文件分类隔离和数据安全保护。

本系统采用文件夹级权限控制方案：

- 默认情况下所有文件夹均为公开目录
- 所有用户均可访问公开目录
- 仅对需要保护的目录单独配置权限
- 文件自动继承所在文件夹权限
- 无需对单个文件逐一授权

## 权限管理方式

share_manage 管理员可通过目录树中的 **“权限”** 按钮配置文件夹访问用户，保存后立即生效。

若取消所有用户授权，系统将自动移除该目录的权限配置，该目录重新恢复为公开目录。
