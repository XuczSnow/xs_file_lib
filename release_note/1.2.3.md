# 1.2.3 版本说明

> 本版仅含安装脚本（install.py）的 Windows 服务安装策略调整与文档同步，无业务代码改动。

## 🛠 Windows 服务安装策略：仅 NSSM，废弃计划任务

背景：计划任务（`schtasks`）路径存在两个实际问题——
1. **交互弹窗**：`/Run` 或登录触发时以交互会话跑 `service_run.bat`，cmd 控制台窗口挂住不消失；
2. **归属失控**：`--service` 曾用管理员建过 SYSTEM 归属的旧任务（`ONSTART`），普通用户终端**无法查询/触发/删除**（`拒绝访问`），形成"任务还在但没人管得了"的孤儿。

因此 Windows 服务安装收敛为**单一 NSSM 路径**：

- `install.py --service`（Windows）：
  - **管理员闸门**：`net session` 探测，非管理员直接拒绝并提示提权重跑（NSSM 装服务需 `SeServiceManagerPrivilege`）；
  - **仅 NSSM**：`find_nssm()` 探测（用户 PATH → 项目根 `nssm.exe`），命中即装真服务 `XsFileLib`（开机自启 + 崩溃守护，`AppDirectory` / 日志重定向 `logs/service.log`，幂等先 remove 后建）；
  - **未检测到 `nssm.exe` 时不安装、也不回落计划任务**：打印自助指引（下载 https://nssm.cc/ → 放入项目根或 PATH → 以管理员重跑）+ 手动 `nssm install …` 命令兜底；
  - 死代码清理：删除 `write_service_runner`（`service_run.bat` 生成器）与 `launch_cmd_shell_args`（无调用方）。
- `restart_command` 联动：Windows 仅预填 `nssm restart XsFileLib`；`KNOWN_RESTART_CMDS` 保留旧 schtasks 组合条目——仅用于识别/清空历史预填值，不再生成新值。
- `--uninstall`（Windows）：探测移除 NSSM 服务 `XsFileLib`（`sc query` 到才动）+ **幂等清理旧版遗留的计划任务 `XsFileLibService`**（`/Query` + `/Delete`，未装即跳过）+ 删历史生成的 `service_run.bat`（若存在）。

## 🖼 共享页首屏入口按模式区分（相册 vs 普通）

- **问题**：相册模式（`share_mode=album`）的共享页首屏复用普通"文件预览"卡片（`📄 文件共享 + [预览文件]`），不符合相册设定；根因是 `/api/share-info` 早返回 `share_mode`，但 `share.js` 首屏填充时未使用。
- **修复**（纯前端，`share.html` + `share.js` onload）：首屏按模式三态渲染——相册 → `🖼️ 相册共享 + [进入相册]`；文件夹 → `📁 文件夹共享 + [预览文件]`；单文件 → `📄 文件共享 + [预览文件]`。密码框、验证流程、验证后的 `renderAlbum`/`renderFolder` 不变。
- `verifyShare` 按钮加 `id="verifyBtn"` 供文案切换；非相册共享（`share_mode` 缺省/`normal`）行为与原版完全一致。

## 🩺 健康检查端点（U3 A 基础版）

- 新增 **`GET /api/health`**（公开，无需 token）：返回 `{ok: true, version, ts}`，供 NSSM 守护 / 外部 uptime 监控 / 探活。
  - `ok` 恒为 `true`（端点可达即 true，探活只回答"服务进程活着且能响应"）；
  - `version` = 当前 `release_note/` 最新版本号（复用 `updater.latest_version()`，读目录毫秒级）；
  - `ts` = 服务端 Unix 时间戳。
- 刻意**公开**（不进 `main.py` 的 `require_token` 保护列表，与媒体缩略图 / `api/share-info` 口径一致）——探活就是匿名调的；不吐 config/路径等敏感信息。
- 后续可扩展 B/C 层字段（dash_ok / git_head / 计数等），本版只做基础 A。
- 回归：`tests/test_regress.py` +1（`test_health_endpoint_public`：匿名 200 + 字段齐全 + 带 token 行为一致）。

## ⚠️ 存量部署迁移提示

曾用旧版 `--service` 装过计划任务 `XsFileLibService` 的机器：
- 跑一次 `python install.py --uninstall`（幂等清理旧任务 + `service_run.bat`）；
- 需要服务时下载 `nssm.exe` 放项目根，管理员重跑 `python install.py --service`。

> 无回归用例变化（纯安装脚本 + 文档改动，pytest 基线不变）。
